# Firewall_Lab



🔥 Lab 5.10: Firewalls (Zybooks)

This lab explores the role of host-based firewalls in securing a system by controlling network traffic. It involves creating and modifying firewall rules to block or allow protocols, ports, and services using Windows Defender Firewall and analyzing the results with nmap.

🧠 Learning Objectives

--Use nmap to scan for open ports

--Configure rules to allow/block protocols, ports, and services

--Understand how firewalls protect systems from unauthorized access

🖥️ Environment
VMs Used:

--ZyWin01 (Windows Server 2022)

--ZyWin02 (Windows Server 2022)

✅ Tasks Completed
1) Allowed ICMP packets through the firewall

2) Scanned target system ports using nmap

3) Blocked HTTP access by denying TCP port 80

4) Disabled file sharing via service-based firewall rules
